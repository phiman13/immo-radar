## Design Context

### Users
Philipp Herrlich — Einzel-User, sucht geduldig eine Kauf-Immobilie in der Region Tutzing am Starnberger See. Nutzt das Dashboard auf dem Desktop, tagsüber / am Wochenende. Kein Marketing-Publikum — persönliches Präzisionswerkzeug.

### Brand Personality
3 Wörter: **methodisch · lokal · geduldig**

Nicht: Business-Dashboard, nicht: Luxury Real Estate Marketing. Eher: ein präzises, persönliches Kartierungswerkzeug. Wie ein gut gemachtes Lagebuch trifft auf ein Feldtagebuch eines Landvermessers.

### Aesthetic Direction
- **Theme:** Hell (Light Mode) — Property-Fotos brauchen weißen Hintergrund
- **Palette:** Warmweißes Papier (oktch(97% 0.006 120)) + Tannenzapfen-Grün als Akzent (oklch(45% 0.13 150)) + Tiefes Schiefer als Text
- **Fonts:** Bricolage Grotesque (Überschriften) + Schibsted Grotesk (Body) + Azeret Mono (Zahlen/Preise)
- **Anti-references:** Keine Business-Dashboard-Ästhetik (Grau-auf-Grau), kein Luxury-Real-Estate-Marketing (Cinzel + Gold), kein "AI-Slop" (lila Gradienten, glassmorphism überall)

### Design Principles
1. **Zahlen zuerst** — Preis/m² ist die wichtigste Information. Immer prominent, immer tabellarisch (Azeret Mono).
2. **Keine ablenkenden Dekorationen** — Jedes visuelle Element muss Informationen tragen. Kein Rauschen.
3. **Vertrauen durch Präzision** — Klare Hierarchie, konsistente Status-Farben, keine Ambiguität.
4. **Lokal verwurzelt** — Das Grün des Starnberger-See-Waldes. Geerdet, nicht tech-blau.
5. **Ein Klick zur Entscheidung** — Vom Listing zur Exposé-URL in maximal 2 Interaktionen.
